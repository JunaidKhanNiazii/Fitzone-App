# FitZone – Vision-Based Gym Monitoring System

FitZone is an AI-based fitness application that automates workout tracking using computer vision, pose detection, and face recognition. The system removes the need for manual data entry and provides a smarter way to monitor exercises in real time.

### Installation Steps

1. Download the APK file from the repository  
2. Transfer it to your Android device (if needed)  
3. Enable "Install from Unknown Sources" in settings  
4. Open the APK file and install the app  
5. Launch the app and start using FitZone  

---

## Project Overview

Traditional fitness applications require users to manually log exercises and repetitions. FitZone solves this problem by using AI to automatically detect exercises and track performance.

The system integrates pose detection for exercise recognition and face recognition for user identification. All data is processed and stored in real time using a scalable backend.

## Usage Notes

- Ensure proper lighting conditions  
- Keep the full body visible in the camera frame  
- Maintain an appropriate distance from the camera

## Limitations

- Accuracy may vary with lighting and camera quality
